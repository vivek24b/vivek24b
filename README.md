### My Focus

I build backend systems, reliable data pipelines, and developer infrastructure. My focus is on writing predictable, observable software that holds up under load.

* **System Design:** Designing modular, testable service architectures and resilient REST/RPC APIs.
* **Data & Storage:** Schema design, query optimization, and caching strategies across relational and document stores (PostgreSQL, Redis, MongoDB).
* **Execution & Tooling:** Automated deployment pipelines, containerized environments, and custom automation to eliminate operational toil.
